# Test classes that skip at least one test on a CI runner, and why.
#
# Checked by tools/check-ci-skips.php against the JUnit log of the integration
# job. A class that skips and is NOT listed here fails the build by name; a
# class listed here that skips nothing prints as stale and should have its line
# deleted. Same contract as test/Fuzz/known-form-gaps.php: a subset comparison,
# so the file records accepted gaps and nothing else.
#
# ## This list got much shorter on 2026-09-23
#
# It used to hold 39 classes, 37 of which skipped because the runner could not
# CONNECT to a database at all — `database/` held incremental migrations and no
# schema, so nothing in the repository could build one. `database/base-schema.sql`
# and `database/ci-seed.sql` now can, and the job went from 3,085 assertions and
# 195 skipped tests to ~4,227 and 38.
#
# What is left is a different kind of gap, and a healthier one: every entry below
# is about the CONTENT of the seed or about the runner itself, not about the
# absence of a database. Most of them name a row the seed does not yet invent,
# and each is a small, separable piece of work rather than a structural limit.
#
# Keep the reasons specific: "needs a row the seed lacks" is fine, "environment"
# is not. And measure them — the first draft of the old file guessed four entries
# from filenames and three of them were wrong.
