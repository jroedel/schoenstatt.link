# The pages the SQL recording is taken from. One path per line; `#` comments and blank
# lines ignored. Read by tools/sql-surface.sh.
#
# Chosen to reach every table the application queries, not to be a second smoke suite:
# what is recorded is the SQL each page issues, and two pages that differ only in their
# markup issue the same statements. One locale is enough for the same reason — the locale
# changes which catalog is read, not which query is built.
#
# A page added here grows the recording, which is the point: a table nothing in this list
# reaches has no contract, and the SQL it issues can change unnoticed. tools/sql-surface.sh
# warns when a path stops answering, because a 404 silently removes its queries.
